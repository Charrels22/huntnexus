# Phase 19 — Factual boss combat profile

HuntNexus already had full creature-detail ingestion for the canonical Tibia catalogue.

Phase 19 reuses that data for synchronized bosses and adds:
- attack type;
- raw abilities text;
- maximum documented damage;
- whether the creature uses spells;
- observed timestamp.

This is Tier B factual evidence.

It does not replace current RubinOT mechanics and does not clear any reconciliation guard.

For Magma Bubble and Soul War, factual combat information can be shown while the final build remains blocked until current RubinOT room mechanics are reconciled.
