# RubinOT modifier coverage

## Confirmed from official RubinOT sources

- Guild Ascension:
  - XP;
  - stamina regeneration;
  - fast exercise;
  - life/mana leech;
  - critical;
  - main skill;
  - Weapon Proficiency XP;
  - familiar damage;
  - loot;
  - race damage;
  - elemental damage;
  - elemental defense.
- VIP:
  - +10% Weapon Proficiency experience.
- Loyalty:
  - account-level permanent skill bonus from 0 to +10 according to Loyalty points;
  - vocation-specific affected skills.
- Equipment Preset:
  - designed for quick switching, including hunt/elemental-resistance contexts.
- Huntfinder:
  - official hunt, XP/h, profit/h, set, imbuement and charm recommendation surface.
- Prestige Arena:
  - special context where some systems/effects are explicitly excluded.

## Not yet confirmed as RubinOT-specific official mechanics

Current indexed official-source search did not produce a dedicated RubinOT source for:
- Soulcores / Animus Mastery;
- Bounty;
- Talisman.

These names must not be modeled as RubinOT-specific custom bonuses until an official RubinOT source or an authoritative base-Tibia source is attached. They may later appear as base-Tibia mechanics or community/session modifiers.

## RTC

Official RubinOT pages expose world classifications such as Updated to RTC / Native RTC and server rules mention RTC automation behavior. RTC should be modeled as world/context metadata, not as a numeric hunt-performance modifier unless a specific mechanical effect is sourced.
