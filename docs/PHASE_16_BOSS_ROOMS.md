# Phase 16 — Boss Room foundation

Boss recommendations are modeled separately from normal hunting.

Boss-room data is version-sensitive and keeps:
- boss identity;
- room/add creatures;
- phases;
- mechanics;
- required/avoid actions;
- elemental evidence;
- spell guidance by vocation;
- item/build guidance;
- patch/version validity;
- source tier and confidence.

The model explicitly allows RubinOT Tier A overrides to supersede base Tibia mechanics when exact current RubinOT behavior is sourced.

No mechanic is inferred merely from the boss name.
