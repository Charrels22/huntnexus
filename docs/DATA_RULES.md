# Regras de Dados

## 1. Separação de camadas

Nunca misturar:

- fatos Tibia;
- overrides RubinOT;
- observações comunitárias;
- opinião/editorial.

## 2. Histórico

Alterações RubinOT são versionadas com:

- source_id
- observed_at
- valid_from
- valid_to
- patch_version

Um novo patch cria uma nova versão.

## 3. Confiança

- A: RubinOT oficial
- B: TibiaWiki/APIs/TibiaMaps
- C: trackers/logs
- D: guias editoriais

## 4. Sessões de hunt

Sempre que disponível, registrar:

- servidor;
- data;
- patch vigente;
- hunt;
- duração;
- vocação;
- level;
- party size;
- XP;
- XP/h;
- Raw XP/h;
- loot;
- supplies;
- balance;
- damage;
- healing;
- kills;
- equipamentos;
- imbuements;
- charms;
- prey;
- boost;
- stamina;
- Wheel;
- RTC;
- modificadores RubinOT.

## 5. Estatística

Nunca usar somente o recorde.

Por hunt + vocação + faixa de level + party size + patch, calcular:

- N;
- mediana;
- P25;
- P75;
- P90;
- média aparada;
- dispersão;
- recência.

## 6. Qualidade

Sessões incompletas podem ser armazenadas, mas recebem qualidade menor e podem ser excluídas de benchmarks.

## 7. Proveniência

Toda recomendação futura deve conseguir responder:

> Quais fontes sustentam essa conclusão?
