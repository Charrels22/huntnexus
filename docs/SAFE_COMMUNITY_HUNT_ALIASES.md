# Safe HuntAnalyser hunt aliases

This migration contains only high-confidence community-title variants.

Mapped:
- Podzilla Quaras → Podzilla
- Azzilon Castle party/spelling variants → Azzilon Castle
- Gloom Pillar event variants → Gloom Pillars
- Brain Grounds + monster/solo descriptor → Brain Grounds
- Nimmersatt's Breeding Ground floor/party/modifier variants → Nimmersatt's Breeding Ground

Intentionally unresolved:
- Energy Library
- Fire Library
- titles that describe subareas, routes, event-only names or custom shorthand without a unique canonical hunting-place match.

Reason: merging distinct subareas into a broader canonical hunt would contaminate observed XP/profit/kill-mix analytics.
