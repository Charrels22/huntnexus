# HuntNexus Recommendation Preview

Function:

`huntnexus_recommendation_preview(vocation, level, objective, party_size, limit, defensive_items_per_slot)`

The response keeps evidence separated into:
- ranking;
- factual hunt profile;
- observed performance and kill mix;
- defensive equipment candidates.

The preview is not the final recommendation engine.

Future layers:
- offensive equipment;
- imbuements;
- spells and rotations;
- charms and prey;
- RubinOT exact overrides;
- boss-room mechanics;
- owned/available equipment.
